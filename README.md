# Goed Gezien

**Goed Gezien** is an Android application designed to help older adults in the Netherlands, particularly those aged 80 and above, understand food products more easily.

By scanning a product's barcode, users can access available product information through the Open Food Facts database. The app focuses on simplicity, readability, and accessibility.

## Features

- **Barcode scanning:** Scan food products using the phone's camera.
- **Product information:** Retrieve available ingredients and nutritional information.
- **Accessible design:** Large text, clear buttons, and simple navigation.
- **Jumbo-inspired style:** A recognizable interface with yellow as the primary color.

## Technology

- Kotlin
- Android Studio
- CameraX
- Barcode scanning library
- Open Food Facts API

## Getting Started

1. Open the project in Android Studio.
2. Allow Gradle to synchronize the dependencies.
3. Connect an Android device or start an emulator.
4. Grant camera permission when prompted.
5. Run the application.

An internet connection is required to retrieve product information.

## Data Source

The app uses the [Open Food Facts API](https://world.openfoodfacts.org/) to retrieve available food product data.

Product information may be incomplete or inaccurate. Always check the packaging for essential information, especially regarding allergens.

## Author & Purpose

This project was developed for **educational purposes** as part of a learning project. It is intended to explore Android app development, barcode scanning, API integration, and accessible interface design.

The application is not intended to replace professional nutritional advice.

## Project Goal

Goed Gezien aims to make food product information easier to access and understand for Dutch older adults through an accessible and intuitive mobile application.
